# Ricgraph 3.5 Compatibility Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task by task with TDD and a final review.

**Goal:** Retrieve complete Ricgraph results and recognize Pure research-output UUIDs in BackToPure.

**Architecture:** One shared paging reader, consumed by existing workflows; the existing UUID helper becomes representation-aware. Preserve workflow signatures, retries and Pure apply behavior.

**Tech Stack:** Python 3.10+, requests, pytest, Flask.

**Spec:** `docs/superpowers/specs/2026-11-19-ricgraph35-design.md`

## Global Constraints

- No Pure updates; the final source-data check is proposal-only.
- Preserve server-local changes; transfer only compatibility changes with backups.
- Keep Ricgraph 3.5 and the current 2026 graph.
- Maintain legacy single-page/string-URL compatibility.

## Review Focus

- A later page failing must stop the job, not return a partial successful collection.
- Filters must remain present on continuation requests.
- A loop, malformed cursor/record or empty intermediate page must not silently omit data.
- An unrelated UUID-bearing URL or non-output node must not become an output UUID.
- A DOI-less output must survive the actual workflow selector.
